# Locomotive nickname reference

[Architecture: collection filters](architecture.md#collection-filters)

The authoritative presentation table is [locomotive-nicknames.ts](../src/lib/locomotive-nicknames.ts).
It groups exact classes under a familiar Czech nickname or a documented product
name. A shared nickname is not a claim that the vehicles have identical engineering.
This reference changes filter labels only; it never renames collection records.

Reviewed 2026-09-27. Prefer operator/manufacturer sources; the broader historical
coverage uses the cited secondary nickname index. Nicknames can vary by region
(e.g. Bardotka is also called Zamračená); the menu deliberately uses one concise
name per class. These are reference labels, not official vehicle designations.

## Table

“CZ” means ČD, ČSD, ČSD/ČD, ČD Cargo, RJ and RegioJet. “CZ + SK” adds ZSSK and
ZSSK Cargo. Other supported operators are named explicitly. The operator scope
prevents accidental matches to unrelated foreign classes with the same number;
it does not claim that every listed operator has operated every listed class.

## Extending the table

Add an exact class, operator scope and a supporting source to the shared registry;
update this readable table with it. Do not infer a nickname from the first digit,
a superficially similar vehicle or a generated image. Do not broaden Czech railcar
mappings to Slovakia automatically (840 and 811, for example, differ).

Unpowered intermediate cars 060/063 and unverified mappings such as 340/705 keep
their numeric label for now. This is deliberate incomplete coverage, not evidence
that those vehicles have no nickname. Known product names such as Desiro fill the
same useful role without being presented as Czech slang.

Each series remains a separate filter choice: Brejlovec (750), Brejlovec (753),
Brejlovec (754). The original series remains the URL/storage value, preserving
bookmarks and remembered selections. If a mixed catalog option shares a number
across differently named or unknown vehicles, it falls back to the number.
Run `npm run test:collection-filters` after changes.
